# T2S Studio

Native Android application built with Kotlin and Jetpack Compose.

## Design foundation
- Orange & White visual theme
- Material 3 components
- Reusable theme color tokens
- Home screen with branded top bar, content cards and bottom navigation

## Android configuration
- Package: `com.t2sstudio.app`
- Minimum SDK: 24
- Compile / Target SDK: 35
- Kotlin: 2.0.21
- Jetpack Compose with Material 3

## Open
Open this repository in Android Studio and allow Gradle sync to complete.
